# Music Visual Studio Releases

Repository công khai này chỉ chứa installer chính thức và metadata auto update của Music Visual Studio.

Tải bản mới nhất tại [GitHub Releases](https://github.com/colin-dmme/music-visual-studio-releases/releases/latest).

Source code và private key cấp bản quyền không được lưu trong repository này. Có thể dùng `SHA256SUMS.txt` trong từng release để kiểm tra file tải về.
